## Responsive Product Pricing Cards
A clean, responsive SaaS pricing-page UI built with HTML, CSS, and vanilla JavaScript. It includes three pricing plans, a monthly/yearly billing toggle, featured plan styles, accessibility support, and a mobile-friendly card layout.

---

### Features
- Monthly and yearly billing options
- Starter, Pro, and Team pricing plans
- Automatic price, billing period, and savings updates
- "Popular" and "Best Value" plan ribbons
- Responsive one-column layout on smaller screens
- Prominent focus states for keyboard navigation
- Screen-reader status announcements
- Reduced-motion support
- Hover and price-switch animations
- Google Fonts integration with system-font fallbacks
